# Kotlovan

Чит-мод **Котлован v2.0** для **Minecraft 1.16.5** (Fabric). Красивое кликабельное GUI в стиле Delta, широкий набор модулей и плавная KillAura.

## Модули
- **Движение** — Fly, Speed, Sprint, Step, AirJump, Spider
- **Комбат** — KillAura (плавная), InstantAttack, AutoTool
- **Игрок** — NoFall, Nuker
- **Рендер** — FullBright

## Управление
- **Правый Shift** — открыть ClickGUI (настройки модулей)
- Хоткеи модулей: R / F / C / P / N / H / V / U / J / K / T / I

В GUI: вкладки категорий сверху, клик по модулю — вкл/выкл, клик по значению — изменить.

## Сборка
Требуется: JDK 17, Gradle 7.6, Fabric Loom 0.12.56, yarn `1.16.5+build.10:v2`, fabric-api `0.42.0+1.16`.

```
gradle build --no-daemon
```

Готовый мод: `build/libs/kotlovan-2.0.jar`.

## Установка
1. Установи Fabric Loader для 1.16.5 и Fabric API `0.42.0+1.16`.
2. Положи `kotlovan-2.0.jar` в папку `mods/`.
3. Запусти игру — ты автор.
